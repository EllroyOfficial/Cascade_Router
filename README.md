## 这个项目在做什么

面向**单卡 6GB 显存**上的本地 7B，同时把"**能用**"和"**敢用**"做到：

**① 入口就拦 —— 本地硬规则拦截**
正则词表在**请求进模型之前**命中即停：隐私词锁本地、实时类直连云端、垃圾输入（纯标点/空壳）直接拒答、工具动作先过确认。
⇒ **能靠规则解决的事全部挡在模型之外** —— 既省算力，也从源头少幻觉。

**② 出口就查 —— RAG 事实校验**
回答必须过"**锚点校验**"：数字 / 科目 / 条款号 / 实体，**归一化后逐项与原文比对**（可推导的算式才算数）；
再叠**语义闸**（只拦"整跑题"）、**方向极性**（只拦"说反"）、**出口硬兜**（纯壳 / 过短 / 格式不符 / 整跑题 ⇒ 重试一次或直出原文）。
⇒ **算数交给 Python，事实交给锚点** —— 不指望模型自己算准，也不让"语义相似"冒充"事实正确"。

**③ 在 6GB 显存下的极限工程实践**
本地 7B（`Q4_K_M`，≈4.0GB）与**嵌入件**同卡共存；`num_ctx` 由 2048 提到 **4096**（压测：材料 1800/3000 字**不再截断**、显存峰值 **≈4.13GB**、余量 **≈2GB**、3000 字单次 ≈28.7s）；长材料按"**超硬墙走云端**"；
嵌入件还能**进程内 CPU 跑（0 显存）**，把显存尽量留给生成 —— 一切都是为了在**一张 6GB 卡**上把这件事跑起来。

---

面向**本地 7B 生成模型**的 **混合路由 ＋ RAG 注入 ＋ 出口兜底** 工程。

一句话：**意图路由**（走不走检索、由谁生成）与**生成路由**（本地还是云端）是两个正交决策；所有"说不清"的判据都尽量换成**可核的结构与锚点**，而**涉及计算的数字一律交给 Python**。

## 1. 总逻辑流

```
request(text, meta)
  ├─ P0 输入守卫        纯标点/emoji/空白 且 ≤8 字 → 拒答（不进后续）
  ├─ L1 硬规则层        正则词表，命中即停；多规则命中不同意图 → 降 L2
  │                     （隐私词表置首 → 锁本地；实时强/弱词 → 跳过检索直连云端）
  ├─ L2 轻量语义层      向量 kNN3（bge-small-zh，512 维）＋ 票比阈值；枚举外/低置信 → fail-open 升 L3
  ├─ 意图分流           隐私敏感 → 锁本地；工具调用 → 参数校验 → 确认（有副作用）→ 本地执行
  ├─ RAG 门（仅知识问答）查询改写 → 检索 → 本地复算余弦 → 域内则注入（≤300 字，提问放最后）
  │                     改写后仍 0 命中 → 如实答"未查到"，不注入、不自由发挥
  ├─ 生成路由           隐私/离线 → 锁本地；上下文超硬墙 → 云端；其余 → 本地
  └─ 生成出口           三道防线 → 兜底 → 出口硬兜（Fail → 留档 → 重试一次 → 直出原文）
```

## 2. 三层与守卫

| 层 | 实现 | 关键约束 |
|---|---|---|
| **P0 守卫** | `input_guard`（纯标点/emoji/空白 ≤8 字） | 拒答**不进** L1/L2/检索 |
| **L1 硬规则** | `l1_rules.py` ＋ `routing.yaml: hard_rules` | 只匹配不仲裁；冲突降 L2 |
| **L2 分类** | `l2_vector.py`（kNN3）／`l2_classifier.py`（LLM 备选） | 票比阈值（**票比 ≠ 概率**）；枚举外 fail-open |
| **L3 云端** | `l3_provider.py`（可替换 provider，走宿主运行时的云端会话） | 出口剥离会话尾缀 |
| **本地生成** | `ollama_runtime.py` / `generation.py` | 统一 ask 入口；**串行只开一路** |

## 3. 生成出口：三道防线 ＋ 硬兜

- **三道防线**：①**正则截杀**（`anchors.guard_check`：否定词／财务方向词／数字一致性，双向，默认 `review` 只标不拒）②**定点质检**（余弦落在 0.70–0.85 才触发，三态 `pass/fail/uncertain`，非白名单一律转人工）③**命中句基准**（材料切句 → 取 top-2 拼基准，非主力）
- **兜底 `answer_guard` v2**：语义下限 ＋ **数字一致**（不可省：编造数字在语义上照样通顺）＋ 长度比
- **出口硬兜 `exit_gate`**：**剥壳后有效字数 <15 ／ 纯壳 ／ 格式不符 `expect` ／ 整个跑题** ⇒ **Fail → 留档 → 重试一次 → 直出原文**；**"答对了但多讲了"与"如实说未查到"都算 PASS**
- **契约头**：生成端首行输出 `<<答>>`；出口**先验头、剥头后才给前端**，缺头只计数不判 Fail
- **计算交工具**：`anchors.py` 内 **AST 白名单** 求值（`+ - * / ** %`、括号、`round`；**禁裸 `eval`**）；单位取 **千元/万元**、结果**两位小数**；比较前**先统一单位**，**容差绝对 0.01**（≤0.01 放行并打观察标签；>0.01 判 Fail 且**用 Python 结果覆盖**）

> ⚠️ **口径纪律**：**同一批数据、同一嵌入件口径**下才可比；报"覆盖率 / 误杀率"必须附**抽样对照（程序判定 vs 人眼复核）**。

**回归与自检**

| 指标 | 值 | 说明 |
|---|---|---|
| 主回归 `test_router_v2.py` | **43 / 43 通过** | 每次改动后必跑 |
| 路由判定（150 条测试集，**只跑到决策、不调云端**） | **命中 139 ／ L1 误杀 7 ／ 放行问题 4 ／ errors 0** | 与基线**零漂移** |
| 数字/单位/Python 计算自检 `selftest_numcalc.py` | **8 / 8 PASS** | 覆盖 `100万×13%＝13万`、`1/3≈0.33`、单位混写、编造数字仍拦 |
| 事实闸自检 `selftest_guard.py` | **7 / 7 PASS** | 否定词 / 财务方向 / 数字 三条规则 |

**意图分类 L2**（留出集；`bge-small-zh` 512 维；票比阈值 0.60）

| 指标 | 值 |
|---|---|
| 出手数 / 出手正确率 | **62 / 60 ＝ 96.8%** |
| 低置信安全升级（fail-open 率） | **58.7% → 14.7%**（票比阈值 0.67 → 0.60 前后） |
| 代价（同时报，别只看一个） | 出手错判 **3 → 18**（其中工具/情绪类**正确**出手 1 → 11） |

**出口与判据**（同一批真件；除注明外为 `bge-small-zh` 口径）

| 判据 | 结果 |
|---|---|
| 数字一致闸 | **30 / 30** 拦住"数字被改"（余弦对它失明） |
| 跑题闸（问题级/材料级余弦） | 同域无关拦 **16/30**、方向说反拦 **13/30**（`bge-m3` 口径下为 28/30、22/30）|
| 出口硬兜 | E2E 六类样本 **Fail → 留档 → 重试 → 直出原文** 链路全通；**契约头残留 0/6**；留档两栏齐全；离线回放正例误杀 23/60（其中 11 条是**已知不服从输出**）|
| 语义缓存分离度 | 同义 min **0.829** ／ 不同问题 max **0.565–0.595**（阈值取 0.75）|
| RAG 门（增值税题重抽口径） | 域内 min **0.554** / 中位 0.646 ／ 域外 max **0.559** ⇒ 阈值取 **0.55** |
| 契约头 | 出现率 **0 → 7/14**；出现头时内容服从 **5/7**（基线约 17%）|

**上下文窗口（`num_ctx` 压力测试；本地 7B，串行只开一路）**

| 档 | `prompt_eval_count` | 显存峰值 | 耗时 | 判读 |
|---|---|---|---|---|
| **2048** ＋ 1800 字材料 | **1027** | 4162MB | 2.9s | **已被截断**（同一 prompt 在 4096 下为 2151 ⇒ 丢约一半）|
| **4096** ＋ 1800 字 | 2151 | 4132MB | 9.7s | **不截断** ✓ |
| 4096 ＋ 3000 字 | 2943 | 4132MB | **28.7s** | 不截断，但**延迟可感** |
| 4096 ＋ 300 字 | 1161 | 4132MB | 0.8s | 常规档 |

> **结论**：**4096 起不再截断**，显存余量 ≈2GB（6GB 卡）⇒ 窗口按 4096 配置；长材料仍按"**超硬墙走云端**"处理。

|---|---|---|---|---|

| **`bge-m3`**（legacy） | ollama `bge-m3:latest`（1.2GB） | 1024 | 早期生产嵌入件；现主要用于**离线去重/对照** | ollama 模型库 |

**统一入口与"分消费者"**（`embed_local.py` ＋ `embedding.json`）：

```json
{
  "backend": "ollama",
  "consumers": {
    "l2":        { "backend": "ollama", "model": "qllama/bge-small-zh-v1.5:latest" },
    "exit_gate": { "backend": "ollama", "model": "qllama/bge-small-zh-v1.5:latest" }
  }
}
```

- **`backend`**：`ollama`（HTTP，默认）／**`inproc`**（进程内 torch，**0 显存**，冷加载更短、单条更快；批量较慢但只出现在离线路径）
- **`consumers`**：`l2` 与 `exit_gate` **各配各的** ⇒ 将来换更强嵌入件**只改 `exit_gate` 一节，`l2` 零动**
- ⚠️ **换模型纪律**：保留旧命名、必配对照、**不许静默换**；换模型须**重标阈值**并**触发旧向量缓存作废重建**（缓存有维度哨兵）

|---|---|
| **远程 MCP `quaesto_kb`** | 财会权威信源（企业会计准则／审计准则／税法原文、判断程序、税会差异）——**主力** |

## 7. 配置速览（`routing.yaml`）

| 段 | 作用 |
|---|---|
| `hard_rules` / `conflict_policy` | L1 词表（含隐私、实时强/弱词）与冲突策略 |
| `input_guard` / `privacy_detection` | P0 守卫；隐私双入口（词表 / 前缀显式标记） |
| `intent_classifier` | L2 声明（向量件、枚举、fail-open、超时） |
| `rag_gate` | 域限定、查询改写、置信度阈值、低置信归因五档、注入硬约束 |
| `answer_guard` | 语义下限 ＋ 数字一致 ＋ 长度比；**`number_tol: 0.01`／`derivable_ops`／方向极性词对** |
| `generation_routing` | 本地/云端选择、上下文硬墙、配额降级 |
| `fallback` | 兜底链（显式报错，不静默吞） |
| `rewrite` | 念稿/改写两段式（`provider: cloud｜local`、余弦分档） |
| `exit_gate` | 出口硬兜（有效字数、壳词表、格式期望、跑题阈值、**契约头标记**、留档） |
| `semantic_cache` | 语义缓存（阈值、LRU、维度过滤） |
| `metrics` | 计数器清单（可观测） |

**当前关键阈值（均带实测依据，可配）**：`in_domain 0.55`／`out_of_domain 0.73`／`min_vote_ratio 0.60`／`answer_guard.min_sim 0.60`／`cos_pass 0.80`／`cos_floor 0.70`／`semantic_cache 0.75`／`number_tol 0.01`／`material_fail_min_len 80`。

## 8. 已知限制

- **语义相似只能测"跑没跑题"，测不出事实错** ⇒ 事实判据必须用**锚点**（数字/科目/条款，归一化后比对）
- **"方向说反"是已知盲区**（数字不动、语义又高）⇒ 靠"引用原文直出降级"＋方向极性词对补
- **定性幻觉**（无数字的编造）超出正则/锚点能力域 ⇒ 由**上层模型的领域微调**解决
- **阈值多为暂定值**，须用**领域题库**做正式标定；**换嵌入件必须重标**
- **长材料延迟可感**（3000 字 ≈28.7s）⇒ 超过硬墙应走云端

## 9. 本仓库不含什么

`.hf_cache/`（模型权重，含 Laya）、`.venv/`、`__pycache__/`、`*.bak-*`、**含真实问答的留档**（`exit_gate_fails.jsonl` 等）、`l2_train_vectors.cache.json`、题库 PDF、日志与缓存 —— 见 [`.gitignore`](.gitignore)；此外，**内部设计文档（`DESIGN.md`/`TESTS.md`/`OPTIONS.md`）与判分、评估产物（`judge_*.jsonl`、`L2_CLS_EVAL_*.json`）也不随公开仓库发布**。
